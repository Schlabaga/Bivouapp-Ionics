# Bivouapp Ionic

Bivouapp is an Ionic-based application designed to help users discover and share bivouac spots. The app allows users to publish new spots, upload photos, and provide details about the location, services, and accessibility.

## Features

- **Spot Publishing**: Add new bivouac spots with descriptions, coordinates, and ratings.
- **Photo Upload**: Upload and manage photos for each spot.
- **Interactive Map**: Use Leaflet.js to select and display spot locations.
- **Search Autocomplete**: Integrated Google Places API for location search suggestions.
- **Service and Lodging Selection**: Choose from predefined services and lodging types.
- **Responsive Design**: Styled with SCSS for a clean and user-friendly interface.

## Technologies Used

- **Frontend**: Angular, Ionic Framework
- **Backend**: Supabase (for database and authentication)
- **Map Integration**: Leaflet.js
- **Camera Integration**: Capacitor Camera API
- **Search API**: Google Places API
